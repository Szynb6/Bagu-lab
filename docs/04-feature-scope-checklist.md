# 项目功能范围最终定稿（V1.0 用户端 MVP & 后期规划）

> **状态**：✅ **已定稿（仅规划，尚未开始开发）**
>
> **技术栈**：Vue 3（Vite + TS + Pinia + Vue Router + Tailwind CSS） · Spring Boot 3 + MyBatis-Plus + Sa-Token · PostgreSQL 17 · Redis 7.4 · RustFS（S3，复用服务器现有中间件 · 方案 A）。

## 一、V1.0 首批开发范围总览（纯用户端）

经过裁剪后，**V1.0 极度聚焦于现有 9 大模块（约 390+ 题 · 103 张图解）的高效背诵闭环**：

| 维度 | V1.0 首批落地精简清单 |
| :--- | :--- |
| **前端页面（5 页 + 1 弹窗）** | `/login` 登录页 · `/` 复习仪表盘 · `/bank` 题库目录 · `/study` 闪卡背诵 · `/read/:slug` 沉浸通读 · 全局 `Ctrl+K` 搜索弹窗 |
| **数据库表（PG17 · 6 张表）** | `sys_user` · `kb_module` · `kb_chapter` · `kb_question` · `study_progress` · `study_review_log`（模拟面试 2 表延至二期 Flyway `V2` 迁移） |
| **Redis 7.4（`db = 2`）** | Sa-Token 登录会话 · `Bitmap` 每日打卡与热力图 · 模块/题目热点缓存 |
| **RustFS（`bagu-images` 桶）** | 由 Python 导入脚本一次性上传 103 张原理图，前端闪卡/通读页正常展示并支持灯箱放大 |
| **后端接口（4 组 · 15 个接口）** | Auth（登录/注销/当前用户）· Knowledge（模块/通读/筛题/单题/全局搜索）· Study（刷题队列/SM-2打分/收藏/助记）· Dashboard（仪表盘/热力图/错题本） |
